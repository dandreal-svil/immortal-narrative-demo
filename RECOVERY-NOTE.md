# Recupero temporaneo del frontend Work

La demo pubblica usa temporaneamente gli asset pubblici recuperati dal sito Work originale:

- CSS: `index-CXYED7y6.css`;
- fotografia: `hero-1891-photo.png`.

Il JavaScript deterministico è ricostruito nel repository pubblico tramite i file ordinati in `chunks/`.

Questa dipendenza è temporanea. Domenica, con il ripristino della modalità Work, il frontend e il backend definitivi saranno riallineati nel progetto originale oppure gli asset verranno vendorizzati con una decisione esplicita.
